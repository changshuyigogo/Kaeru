# 追加改動：稅抜合計的達標狀態

貼給 Claude Code。這是在原本 handoff 之上的一個小改動，只動新增收據表單裡的一行。

---

新增收據表單的「稅抜合計」那一行要加達標狀態。設計稿在 `Kaeru 產品畫面.dc.html`，截圖是 `screenshots/25-threshold-under.png`、`26-threshold-met.png`、`27-threshold-exact.png`。

**要加的東西**

稅額區塊（`#F4F2EF`）裡的「稅抜合計 ¥X」後面接一個狀態文字，跟著輸入即時更新：

- 稅抜合計未滿 5,000 円：`#B08D74`，文字「未達 5,000 円 · 還差 ¥407」，差額 = `5000 - 稅抜合計`，跟著金額算
- 稅抜合計滿 5,000 円（含等於）：`#93A392`，文字「已達 5,000 円」

樣式：10.5px、`font-weight:600`、`margin-left:7px`，跟稅抜合計同一行同一區塊，不要另外開一塊。

**為什麼要加**

日本退稅門檻是稅抜滿 5,000 円，不是含稅。含稅 4,979 回推稅抜只有 4,593，其實不能退，但使用者看到「快五千了」會誤以為過了。原本畫面只顯示稅抜金額，沒告訴使用者這樣還不能退。

**邊界值**

稅抜剛好 5,000 算已達標。判定用 `>=`。

**範圍限制，不要多做**

- 只加這一行狀態文字
- 不要顯示同一間店同一天的合計
- 不要加補買提示、不要加額外說明段落、不要新增區塊
- 不要動這個表單的其他任何部分

**混合稅率模式**

選「兩種都有」時，判定用兩格的稅抜合計（`v8/1.08 + v10/1.10`），狀態文字接在該區塊的「稅抜合計」那一行，規則相同。

顏色用既有色票，不要新增。
